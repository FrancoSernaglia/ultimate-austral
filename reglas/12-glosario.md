# 12. Glosario

Términos que se usan en la cancha. En Argentina las llamadas se dicen en inglés, así que conviene que todos las aprendan así.

## Llamadas (lo que se grita)

| Llamada | Qué significa |
|---|---|
| **Stalling, 1, 2... 10** | la cuenta de la marca |
| **Foul** | me hicieron falta |
| **Contest** | no estoy de acuerdo con la llamada |
| **Retracted** | retiro mi llamada |
| **Play on** | cobré, pero el juego sigue porque no afectó |
| **Travel** | el lanzador se movió con el disco |
| **Fast count** | la marca cuenta rápido o mal |
| **Straddle / Disc space / Wrapping / Vision** | infracciones de posición de la marca |
| **Double team** | dos defensores encima del lanzador |
| **Pick** | me trabaron mientras marcaba |
| **Violation** | se rompió una regla (genérico) |
| **Offside / False start** | alguien se movió antes del pull |
| **Brick** | el pull salió directo afuera, arrancamos en el brick |
| **Up!** | el disco está en el aire (aviso, no llamada) |
| **Disc in** | reanudamos |
| **Delay of game** | están demorando |
| **Injury** | lesión |
| **Technical / Stop** | frenen, hay peligro o un problema |
| **Time-out** | pausa de 75 s |
| **Goal** | es gol |

## Conceptos

| Término | Qué es |
|---|---|
| **Lanzador (thrower)** | el que tiene el disco |
| **Receptor** | cualquier atacante que no es el lanzador |
| **Marca (marker)** | el defensor que cuenta y marca al lanzador |
| **Pivote** | el pie (u otra parte del cuerpo) que el lanzador mantiene fijo |
| **Pull** | el lanzamiento con el que la defensa empieza cada punto |
| **Brick** | marca a 18 m de la línea de gol donde arranca el ataque si el pull sale directo afuera |
| **Zona central** | la parte de la cancha entre las dos zonas de gol (incluye las líneas de gol) |
| **Zona de gol (end zone)** | donde se mete el gol |
| **Turnover (turno)** | cambio de posesión |
| **Down** | el disco tocó el piso |
| **Stall-out** | la cuenta llegó a 10 sin pase |
| **Check** | el toque del disco que reanuda el juego |
| **Contacto mínimo** | roce sin fuerza que no cambia el movimiento del otro; no es falta |
| **Juego muerto** | momentos en que no puede haber turnover (antes del pull, mientras se lleva el disco al pivote, antes del check) |
| **Mantener la atrapada** | seguir con el disco trabado entre dos partes del cuerpo, incluso al caer |
| **Ratio 4:3** | en mixto, 4 de un género y 3 del otro por punto |
| **ABBA** | apodo de la Regla A de ratio prescrito (se alterna cada dos puntos) |
| **Spirit of the Game** | el espíritu del juego: autoarbitraje y respeto |
| **Círculo de espíritu** | ronda de los dos equipos juntos al final del partido |

## Jerga de juego (no son reglas, pero se usan)

| Término | Qué es |
|---|---|
| **Backhand** | lanzamiento de revés |
| **Forehand / flick** | lanzamiento de derecha, con dos dedos |
| **Hammer** | lanzamiento por encima de la cabeza |
| **Huck** | pase largo |
| **Layout** | tirarse para atrapar o bloquear |
| **D / block** | bloquear o desviar un pase |
| **Force** | hacia qué lado la marca deja lanzar |
| **Stack** | formación del ataque (vertical, horizontal) |
| **Handler** | jugador que distribuye el disco |
| **Cutter** | jugador que corre para recibir |
| **Callahan** | interceptar en la zona de gol que ataca tu equipo: es gol directo |
