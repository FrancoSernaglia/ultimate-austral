# Cortes

Moverse sin disco para quedar libre. Con 6 personas (3v3) cada uno corta muchísimo, así que es la habilidad que más se nota en el partido.

Progresión:
1. Corte en V (amagar en una dirección, frenar, salir en la otra).
2. Timing: cortar cuando el lanzador está listo para lanzar (recién atrapó y pivoteó).
3. Despejar: después de cortar y no recibir, salir del camino para el próximo.
4. Corte profundo (ir largo cuando el defensor está pegado de frente).

| Ejercicio | Nivel | Min |
|---|---|---|
| `corte-en-v.md` | inicial | 10-15 |
| `go-to.md` | inicial-intermedio | 15 |
| `corte-profundo.md` | intermedio | 10-15 |
