# Recepción

La mitad de los turnovers de un equipo nuevo son discos que tocan las manos y se caen. Se entrena casi siempre dentro de otros ejercicios, pero vale tener 5-10 minutos dedicados cuando se vea que cuesta.

Técnicas:
- **Sándwich (panqueque):** una mano arriba y otra abajo, aplaudiendo el disco. La más segura; la default.
- **Pinza (C):** con una o dos manos al borde, para discos altos o bajos.
- **En carrera y en el aire:** atacar el disco, no esperarlo.

|---|---|---|
| `sandwich-y-pinza.md` | inicial | 5-10 |
| `atacar-el-disco.md` | inicial-intermedio | 10 |
