# Juegos y partidos

Cada práctica termina con partido (pedido del equipo). Con 6 personas el formato base es 3v3; los juegos condicionados sirven para que el partido "enseñe" lo que se trabajó ese día.

| Archivo | Para qué |
|---|---|
| `partido-3v3.md` | Formato base del cierre: cancha, reglas, duración |
| `juegos-condicionados.md` | Reglas extra para meter en el partido según el foco del día |
| `juegos-reducidos.md` | 2v2 y juegos de posesión para cuando son 4 o 5 |
