# Juegos condicionados

Una regla extra en el primer partido del día para que el juego empuje el foco que se trabajó. El segundo partido es libre.

| Foco del día | Regla extra |
|---|---|
| Backhand / forehand | Solo vale el gol si el último pase fue con el lanzamiento del día |
| Pivote | La cuenta llega solo hasta 6: hay que pivotear rápido |
| Recepción | Drop propio = el otro equipo suma un punto |
| Corte en V | Prohibido el pase de más de 15 m: todos los cortes tienen que volver al disco |
| Despejar | Si dos atacantes quedan a menos de 3 m, turnover |
| Corte profundo | Gol desde fuera de la zona de un pase largo vale 2 |
| Marca | La marca cuenta hasta 8 y el lado forzado es obligatorio (forehand) |
| Defensa | Turnover provocado por la defensa vale 1 punto extra |
| Pull | Cada punto arranca con pull; si cae afuera, el ataque arranca en el medio |
| Spirit | Cada llamada se explica con el número de regla (`reglas/`) |
| Todos tocan | El gol vale si los 3 atacantes tocaron el disco en esa posesión |
